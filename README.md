# 🔬 Semiconductor Device I-V Analyzer & Parameter Extractor

반도체 소자(MOSFET)의 측정 데이터로부터 핵심 전기적 파라미터를 자동으로 추출하고 분석 그래프를 생성하는 Python 기반 소자 특성 분석 도구입니다.

---

## 📌 프로젝트 개요 (Overview)
반도체 공정 및 소자 측정 시 발생하는 수천 줄의 전압-전류(I-V) 실측 데이터를 파싱하여 소자의 성능을 결정하는 **4대 핵심 파라미터($V_{th}, I_{on}/I_{off}, SS, g_m$)**를 자동으로 계산하고 고해상도(300 DPI) 듀얼 스케일 그래프로 시각화합니다.

---

## ⚡ 핵심 추출 파라미터 및 물리적 의미

| 파라미터 | 추출 방식 | 반도체 소자에서의 물리적 의미 |
| :--- | :--- | :--- |
| **문턱전압 ($V_{th}$)** | 최대 $g_m$ 지점 선형 외삽법 (Linear Extrapolation) | 채널이 강하게 반전(Strong Inversion)되어 켜지는 기준 전압 |
| **On/Off 전류비 ($I_{on}/I_{off}$)** | 최대 구동전류 / 최소 누설전류 비율 | 로직 소자의 스위칭 성능 및 대기 전력(Off-state leakage) 품질 지표 |
| **Subthreshold Swing ($SS$)** | 문턱전압 이하 역기울기 ($[d\log_{10} I_D / dV_{GS}]^{-1}$) | 게이트의 채널 제어력 평가 (이상적인 상온 한계: $60\text{ mV/dec}$) |
| **트랜스콘덕턴스 ($g_m$)** | $g_m = \partial I_D / \partial V_{GS}$ | 게이트 전압 변화에 따른 드레인 전류 증폭 성능 지표 |
